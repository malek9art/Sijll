**سجل** هو تطبيق ويب من فئة المؤسسات (Enterprise) مصمم أولاً للغة العربية (RTL بالكامل) للاستخدام الشخصي، يجمع بين متابعة الحسابات والمديونيات عبر كشوف حساب موحدة، المحاسبة الشخصية، والمستندات — مع طباعة احترافية بجودة البرامج المكتبية، وعمل كامل دون اتصال، ونشر مباشر على GitHub Pages.

> 💡 **حساب افتراضي جاهز:** عند أول تشغيل يُنشأ حساب «عبدالعزيز عبدالغني سلطان عبدالولي عبده» بالريال السعودي مع ٢٥ عملية بترتيبها الزمني (كشف حساب موحد كامل: دائن/مدين/رصيد متتابع حتى ٦٨٬٤٦٩٫٤٣ ر.س).

> 🏷️ **تطوير: Malek Logic** — جميع المستندات والتقارير المطبوعة وشاشات التطبيق موثقة بتوقيع التطوير.

## ✨ المزايا الرئيسية

| المجال | المزايا |
|---|---|
| **دفتر الحسابات (كشف الحساب الموحد)** | حسابات شخصية (مديونية لنا/علينا)، كشف موحد بثمانية أعمدة (الرقم التسلسلي، التاريخ، الجهة المنفذة، رقم المرجع، البيان التفصيلي، دائن، مدين، الرصيد المتبقي)، رصيد متتابع تلقائي، قيود محاسبية مزدوجة بحركتين، قوائم جهات منفذة جاهزة (براق ويسترن يونيون، عالم الصرافة، بنك الكريمي...)، طباعة A4 احترافية |
| **العمليات المالية (منطق محاسبي)** | كل ذمة = **عملية مالية جديدة** (مبلغ على طرف لنا أو علينا) بتاريخ تسجيل واحد فقط — **بدون تواريخ سداد أو استحقاق أو أقساط أو فوائد**؛ السداد يتم بدفعات لاحقة تُنقص الرصيد تلقائياً، مع حالات (مفتوحة/مسددة جزئياً/مسددة/ملغية) وتسويات نهائية وسجل تدقيق |
| **PDF والمشاركة** | تحميل PDF احترافي بمقاس A4 متعدد الصفحات، بنفس خطوط النظام العربية وتشكيل عربي مثالي، مشاركة مباشرة عبر **واتساب** (Web Share API على الجوال + واتساب ويب على سطح المكتب)، إمكانية تحديد رقم المستلم |
| **النسخ الاحتياطي** | رفع واستعادة مباشرة من **Google Drive** (مجلد «سجل - نسخ احتياطية» تلقائياً) عبر OAuth — بديل عملي عن Neon لأن الجميع يملك حساب قوقل. مع تصدير/استيراد JSON محلي مشفر AES-256 كخيار إضافي |
| **قفل الجلسة** | رمز PIN + **دخول بيومتري** (بصمة / Face ID) عبر WebAuthn — يُطلب تلقائياً عند القفل مع PIN كبديل دائم |
| **المحاسبة** | دليل حسابات كامل، قيود يومية مزدوجة القيد مع تحقق التوازن، دفتر أستاذ، أرصدة افتتاحية، تعدد عملات مع أسعار صرف، ميزان مراجعة، ميزانية عمومية، قائمة دخل، تدفقات نقدية، تقادم ديون، تقارير تحصيل ومدفوعات، كشوف أطراف |
| **المستندات** | ٨ قوالب بصياغة قانونية احترافية محكمة (إقرار مديونية والتزام، تعهد، اتفاقية تسوية نهائية، إنذار ومطالبة بالوفاء، وكالة وتفويض، سند قبض وإبراء جزئي، إخلاء طرف وإبراء نهائي، عقد اتفاق والتزام متبادل) — بنود مرقمة، إقرار بالأهلية وحرية الإرادة، **دون أي فوائد**، عناصر نائبة ديناميكية، شهود، أرقام موحدة، رمز QR للتحقق، تواريخ ميلادية وهجرية، مبالغ بالأرقام والكلمات العربية |
| **الطباعة** | تصميم عصري: شريط لوني علوي، ترويسة بشعار وشارات، جداول برؤوس ملوّنة وتظليل متناوب، بطاقات ملخص، صناديق مبالغ، تواقيع مؤطرة · أوراق A4 حقيقية، تكرار رؤوس الجداول، منع كسر الصفوف والتيتّم (orphans/widows)، ألوان دقيقة عند الطباعة |
| **البنية التقنية** | Offline-First عبر IndexedDB (Dexie)، PWA قابل للتثبيت، وضعا الليل والنهار، قفل PIN + بصمة، تشفير AES-256، نسخ احتياطي على Google Drive، سجل تدقيق (Audit Log) |

## 🚀 التشغيل السريع

```bash
npm install
npm run dev        # التطوير — http://localhost:5173
npm run build      # الإنتاج — مجلد dist
npm run preview    # معاينة الإنتاج
```

## 🌐 النشر على GitHub Pages

1. ارفع المشروع إلى مستودع GitHub على الفرع `main`.
2. من إعدادات المستودع: **Settings → Pages → Source → Deploy from a branch → `gh-pages` / (root)**.
3. مشغّل `deploy.yml` المرفق يبني التطبيق وينشره تلقائياً عند كل `push` إلى `main`.
4. سيصبح التطبيق متاحاً على `https://<username>.github.io/<repo>/`.

**لماذا يعمل بلا إعدادات إضافية؟**

| العائق المعتاد | الحل المطبَّق هنا |
|---|---|
| المسارات المطلقة تنكسر في المسار الفرعي | كل الأصول والروابط **نسبية** (`./sw.js`, `./manifest.webmanifest`, `./logo.svg`) |
| توجيه SPA يعطي 404 عند التحديث | **توجيه بالهاش** (`#/ledger`) + نسخ `404.html` احتياطي في المشغّل |
| Jekyll يحذف ملفات تبدأ بـ `_` | ملف `.nojekyll` مُدرج في `public/` ويُنشأ في المشغّل |
| Service Worker لا يُسجَّل في مسار فرعي | التسجيل عبر `new URL("sw.js", document.baseURI)` بنطاق نسبي |
| مخرجات متعددة تعقّد الاستضافة | البناء ينتج **ملف HTML واحد** يحوي كل شيء (`vite-plugin-singlefile`) |

✅ **قائمة تحقق قبل النشر:** البناء ينجح بلا أخطاء TypeScript · الشعار والأيقونة في `public/` · بيان PWA بمسارات نسبية · القفل البيومتري وGoogle Drive يتطلبان HTTPS (متوفر تلقائياً على GitHub Pages).

## 🗄️ نموذج البيانات

- **الأطراف** `parties` — أفراد/شركات/مؤسسات مع بيانات الهوية
- **الديون** `debts` — النوع، المبلغ، العملة، الفائدة، الأقساط، الحالة، الاستحقاق
- **المدفوعات** `payments` — نقد/بنك/تحويل/شيك مع المراجع
- **الحسابات** `accounts` — دليل حسابات هرمي (أصول/خصوم/ملكية/إيرادات/مصاريف)
- **قيود اليومية** `journalEntries` — قيود مزدوجة القيد مع أسطر مدين/دائن
- **القوالب والمستندات** `templates` / `documents` — قوالب قانونية بعناصر نائبة `{{...}}`
- **سجل التدقيق** `auditLogs` — كل عملية موثقة بالوقت والتفاصيل
- **التنبيهات** `notifications` — تذكيرات الاستحقاق
- **دفتر الحسابات** `ledgerAccounts` / `ledgerEntries` — كشوف الحساب الموحدة والقيود المزدوجة
- **الإعدادات** `settings` — بيانات المصدر (شخصي/منشأة)، أسعار الصرف، PIN والبصمة، معرّف درايف

كل جدول مفهرس حسب مفاتيح الاستعلام، والعلاقات طبيعية عبر المعرفات، والترحيلات عبر إصدارات Dexie.

## ☁️ ربط النسخ الاحتياطي بـ Google Drive (خطوة واحدة)

التطبيق يعمل بكامل وظائفه **دون اتصال**، والدرايف اختياري لحفظ نسخك سحابياً:

1. افتح [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials) وأنشئ مشروعاً.
2. فعّل **Google Drive API** من مكتبة الواجهات.
3. أنشئ **OAuth Client ID** من نوع «تطبيق ويب»، وأضف رابط موقعك في *Authorized JavaScript origins* — مثال: `https://<username>.github.io`.
4. انسخ المعرّف والصقه في **الإعدادات ← النسخ الاحتياطي إلى Google Drive**، ثم اضغط «الاتصال».

بعدها يمكنك **رفع نسخة**، **عرض النسخ**، و**الاستعادة** بضغطة واحدة. يستخدم التطبيق نطاق `drive.file` فقط — أي أنه يصل حصراً للملفات التي أنشأها بنفسه ولا يرى بقية ملفاتك.

> بدون ربط: استخدم «تصدير نسخة» ثم ارفع الملف يدوياً إلى drive.google.com — نفس النتيجة.

## 🔐 الأمان

- تشفير النسخ الاحتياطية **AES-256-GCM** عبر Web Crypto (PBKDF2 بعبارة مرور)
- قفل جلسة برمز PIN + **تحقق بيومتري** (بصمة / Face ID) عبر WebAuthn
- نطاق درايف محدود (`drive.file`) — لا وصول لملفاتك الأخرى
- سجل تدقيق شامل لكل إنشاء/تعديل/حذف
- تحقق بالتوازن لكل قيد محاسبي، والتحقق من صحة المدخلات في كل النماذج

## ✅ سلامة المنطق المحاسبي والقانوني

- **توحيد العملات**: كل التقارير (ميزان المراجعة، الميزانية، الدخل، التدفقات) تحوّل القيود متعددة العملات إلى العملة الأساسية عبر أسعار الصرف — لا خلط بين ريال ودولار بعد الآن.
- **قائمة الدخل عن الفترة**: تُحتسب من قيود الفترة المحددة فقط، بينما الميزان والميزانية يعرضان «كما في» تاريخ النهاية (تقارير لحظية) — بعناوين صحيحة لكل نوع.
- **منطق المستندات**: حقلا «سبب الالتزام» و«تاريخ السداد المتفق عليه» يُحفظان فعلياً مع المستند ويُستبدلان في القوالب (`{{debt_reason}}`، `{{due_date}}`) بدل الفراغات، مع تهيئة تلقائية عند تعديل مستند موجود.
- **إقرارات بدون فوائد**: كل القوالب تنص صراحة على عدم وجود فوائد أو زيادات، والعمليات تُسدَّد بدفعات تُنقص الأصل فقط.

## ☁️ العمل دون اتصال

التطبيق يعمل كاملاً دون إنترنت: البيانات في IndexedDB، وكل الموارد (بما فيها خطوط Google العربية) يُخزّنها Service Worker عند أول زيارة، فيعمل التطبيق والخطوط والطباعة وPDF دون اتصال. يظهر مؤشر «دون اتصال» تلقائياً في الشريط العلوي.

## 👤 مصدر المستندات: شخصي أو منشأة

في الإعدادات يمكنك اختيار وضع **«شخصي»** (اسمك فقط) أو **«منشأة»** (اسم جهة + ترخيص اختياري). جميع الحقول اختيارية — ما تتركه فارغاً يُحذف تلقائياً من الترويسات المطبوعة وملفات PDF، فلا تظهر بيانات ناقصة في مستنداتك.
